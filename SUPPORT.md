You can help support us at any time. Here is how you can do that:

	1. You help us understand the files, by writing into README.md in the specific directories what the files do / how to read them.
	
	2. You find / code a Program that can read out the file types in the list below.

	3. A Modloader for the game itself

	4. Fixing up the script and finding final potential remnants I have missed / fixing broken files
	
If you are willing to help, you can do so. However, there are certain requirements.

	1. The program you find must be free. No Trial Programs, no Paid only. Freeware, Shareware, or Freemium is allowed, however the function must be accessible without paying.
	
	2. If you find programs, include links and a semi-proper explanation as to why.
	
	3. Everything you write must be properly annotated. No vague sentences, malware-free links, and most importantely, well explained.
